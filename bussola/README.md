# 🧭 Bússola de Carreira

App de **orientação de carreira de A a Z**: reúne num só lugar as frentes que o mercado mais procura — autoconhecimento, transição, liderança, produtividade, IA no trabalho, inteligência emocional, educação financeira — **+ Oratória & Comunicação** (como falar, como se portar, o que não fazer e como **não ficar no vácuo**).

100% client-side (HTML/CSS/JS puro, **arquivo único**, sem build e sem servidor). Roda offline e publica de graça no GitHub Pages.

## Módulos

| Módulo | O que tem | Interativo? |
|---|---|---|
| 🪞 Autoconhecimento | Teste de perfil estilo **DISC** (8 situações) → perfil dominante + secundário, pontos fortes e pontos cegos | ✅ quiz |
| 🎙️ Oratória & Comunicação | O que **não** fazer, como falar (PREP), presença, e o **Anti-vácuo** com analisador de mensagem | ✅ analisador |
| 🧭 Transição de Carreira | 4 passos + checklist de recolocação com barra de progresso | ✅ checklist |
| 🤝 Liderança | Bom líder × armadilhas + modelo de feedback SCI | conteúdo |
| ⏱️ Produtividade | Matriz de prioridade, blocos de foco + as 3 prioridades do dia | ✅ foco do dia |
| 🤖 IA no Trabalho | Onde rende, anatomia do prompt (Papel+Tarefa+Contexto+Formato) | conteúdo |
| 🧠 Inteligência Emocional | Seletor de **sabotadores** + autorregulação | ✅ seletor |
| 💰 Educação Financeira | **Será?** (3 perguntas antes de gastar) + regra 50/30/20 | ✅ quiz |

## Como rodar

Abra `index.html` direto no navegador (celular ou desktop). Funciona offline.

```bash
python3 -m http.server 8000
# http://localhost:8000/bussola/
```

## Roadmap "do menos custoso pro mais"

| Fase | O que é | Custo | Esforço |
|---|---|---|---|
| **1. MVP estático** *(esta versão)* | App de arquivo único no GitHub Pages | **R$ 0** | feito |
| **2. PWA + histórico local** | Instalar como app no celular, salvar resultados no `localStorage` | **R$ 0** | baixo |
| **3. Conteúdo premium** | Mais testes, vídeos, PDFs exportáveis por módulo | hospedagem ~R$ 0–30/mês | médio |
| **4. Contas + assinatura** | Login, salvar na nuvem, pagamento (B2C) e relatório p/ gestor (B2B) | ~R$ 50–200/mês + taxa gateway | alto |
| **5. App nativo + IA ao vivo** | Loja (iOS/Android), feedback de oratória por IA, mentor virtual | maior | alto |

> A regra do roadmap: **só sobe de fase quando a anterior provar demanda.** A Fase 1 já é vendável/validável sem gastar nada.
